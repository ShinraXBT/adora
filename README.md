# Adora

Public pages of **Adora: Quick Add for J7Tracker (Unofficial)**, a browser extension by [@ShinraHQ_](https://x.com/ShinraHQ_).

- Privacy policy: https://shinraxbt.github.io/adora/privacy/

This repository hosts these pages, plus [`watcher/`](./watcher), a standalone Node.js script that alerts when watched X accounts, or X accounts above a follower threshold, show up on pump.fun with their X linked. Adora is an independent extension, not affiliated with J7Tracker.
